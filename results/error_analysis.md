# Tool-call error analysis (free generation)

Greedy generation of the next assistant turn right after a user request (history from earlier rounds included), parsed and assigned to exactly one category, checked in this order: `no_call` (prose, no `<tool_call>`), `malformed_json` (tag present, body not a `{name, arguments}` JSON object, incl. truncation), `hallucinated_tool` (name not offered), `wrong_tool` (another offered tool), `wrong_arg_keys` (missing/extra argument names), `wrong_arg_type` (value right only as a string, e.g. `"50"` vs `50`), `wrong_arg_value`, else `correct`. Counts are summed over the calibration seeds present (seed count in brackets).
